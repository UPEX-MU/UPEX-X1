# UPEX Catalyst Control Center .135

插件版本：2026.11.03.135

## 本次更新

- 修复 ACR 宽发卡弯语音标识未被识别，导致图标没有随语音出现的问题。补充左右宽发卡及急发卡标识，沿用左右发卡图案；宽发卡不再误判为“变缓”。
- 保留发卡弯的长弯修饰、后续弯道及距离提示。用户已在原问题位置确认发卡图标跟随语音出现。
- 增加 ACR 发车前的未点火、驶向起点、请起步状态属性，供配套仪表读取。采用已有只读采集方式，不新增游戏内诊断钩子。
- 包含 .133 的路书、车辆灯光遥测、自定义布尔遥测和独立更新器修复。

## 更新说明

在插件的在线更新中心检查并更新插件，然后重新启动 SimHub。现有配置会保留；更新前备份，失败时回滚。

本次推送只更新插件。UPEX ACR Rally 仪表是独立安装项目，本插件安装包不会覆盖现有仪表。X1、APEX2 固件版本不变，不会自动刷写设备。

ACR 适配保持已验证的 0.4.0。新电脑仍需通过插件中的 ACR 安装／修复入口安装适配；游戏版本不受支持时停止采集，不猜测状态。

## 验证范围

发布使用本机已实测的同一份 .135 插件。已完成逻辑回归、问题现场播报回放、离线／在线包安装与回滚验证，以及旧更新器兼容校验。宽发卡语音同步已由用户实测确认；不代表所有车辆、语言和赛段组合均已完成实体测试。

在线包符合旧更新器 32 MiB 限制，并继续内置 AVR 刷写工具，客户不必单独安装 Arduino IDE。在线更新清单带签名且下载校验 SHA-256；安装程序本身未做 Authenticode 代码签名。
