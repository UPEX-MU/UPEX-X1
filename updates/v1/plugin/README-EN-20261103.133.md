# UPEX Catalyst Control Center .133

Plugin version: 2026.11.03.133

## Changes

- Fixes valid standalone ACR `Any` speech clips being discarded, including distances and numbered turns. The reported "40 / left 5 / 60" sequence has been confirmed on a physical matrix.
- Adds unnumbered slight left/right turns, consecutive bends including first-left/first-right variants, keep outside, junction left/right and bumps. Slight turns are not assigned an invented numeric grade.
- Includes cut, small cut, dip, brake, junction, keep left/right/inside, long/short turns and numbered tightening combinations. Both grades remain visible in combinations such as left 4 tightening to 2.
- Briefly preserves undisplayed sub-cues during rapid speech without cycling old turns. At most two carryover cues add up to 700 ms; overload handling prevents an indefinitely growing queue of obsolete instructions.
- Uses the traffic-light red/yellow/green palette and white numbers.
- Includes generic and ETS2/ATS vehicle-light telemetry, custom boolean telemetry, and ACR light state, actual indicator phase and voice-synchronized roadbook support.

## Use And Validation

Restart SimHub after updating. Enable roadbook voice synchronization in the matrix settings. Manual physical previews require matrix output enabled; return to live output after previewing.

ACR native observation requires a supported game build and game adapter. Computers without the adapter must use the plugin's ACR install/repair entry. This release retains the verified 0.4.0 adapter and does not add the diagnostic hooks that previously caused crashes. Unsupported builds fail closed.

Unknown instructions are not substituted with an unrelated turn. Two incident captures and a historical speech capture passed replay checks; this is not blanket physical acceptance of all stages, cars, languages or combinations.

Existing settings are preserved with backup and rollback. The online package remains below the legacy updater's 32 MiB limit and includes the AVR tools. This plugin update does not flash devices or change X1/APEX2 firmware artifacts.
