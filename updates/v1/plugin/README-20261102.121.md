# UPEX Catalyst Control Center .121

插件版本：2026.11.02.121

## 固件更新

在收到插件更新提醒后，先完成插件更新并重新打开 SimHub，再从插件内打开在线更新中心，选择对应型号更新固件。无需另行安装 Arduino 或下载独立刷写工具。更新器版本为 2026.11.2.1。

安装包会同时安装与插件配套的更新器。旧更新器被占用时仍可完成升级；新版插件将启动自己的配套更新器，不再使用旧的共享文件。刷写工具、固件和设备检查通过后才关闭 SimHub。

本次没有修改 X1 或 APEX2 固件内容。固件仍由原有签名更新源下载。刷写过程中请勿退出程序或断开 USB。

## 界面更新

包含近期本地 .118 至 .120 的灯效编辑界面调整：统一选灯与颜色入口、紧凑灯效块、更明确的优先级拖动反馈、快捷键按钮文字显示修复，以及遥测设置与导航仪表安装入口调整。

## 升级保护

保留客户已有配置，安装前备份旧插件，安装失败时回滚。在线安装包压缩载荷以兼容旧更新器的 32 MiB 下载限制，解压后的插件与离线安装包一致。

验证记录随发布文件提供。软件验证与实机刷写分开记录，本轮软件检查不代表已经完成客户设备刷写验证。
