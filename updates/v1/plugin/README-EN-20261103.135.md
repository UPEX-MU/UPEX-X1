# UPEX Catalyst Control Center .135

Plugin version: 2026.11.03.135

## Changes

- Recognize ACR left/right open and acute hairpin speech identifiers. Open hairpins now follow the spoken cue instead of waiting for the HUD cue. They reuse the existing hairpin artwork and are not interpreted as an opening-corner modifier.
- Preserve long-corner modifiers, linked corners and distance cues. The user confirmed speech synchronization at the original problem location.
- Add ACR pre-start properties for ignition off, approaching the start and the start prompt, using the existing external read-only collector. No new in-game diagnostic hooks.
- Retain the .133 roadbook, vehicle-light telemetry, custom Boolean telemetry and self-contained updater fixes.

## Installation and Scope

Check for updates in the plugin update center, update the plugin and restart SimHub. Existing settings are retained, with backup and rollback on failure.

This is a plugin-only update. The UPEX ACR Rally dashboard is installed separately; this installer does not overwrite dashboards. X1 and APEX2 firmware versions remain unchanged and no device is flashed automatically.

The verified ACR adapter remains at 0.4.0. New installations still require the ACR install/repair action. Unsupported game versions stop collection instead of guessing telemetry.

## Verification

The release contains the exact locally installed and user-tested .135 plugin bytes. Logic regression, actual speech-capture replay, full/online installation and rollback, and legacy-updater compatibility are checked. Open-hairpin synchronization was user-confirmed; not every vehicle, language or stage combination has been physically tested.

The online installer fits the legacy 32 MiB limit and retains bundled AVR flashing tools, without requiring Arduino IDE. The update catalog is signed and downloads are SHA-256 checked. The installer itself is not Authenticode-signed.
