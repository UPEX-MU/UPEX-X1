# UPEX Catalyst Control Center .133

插件版本：2026.11.03.133

## 本次更新

- 修复 ACR 独立播报使用 `Any` 位置标识时被过滤的问题，包括距离数字和编号弯道。实机已确认“40 → 左5 → 60”三个提示正常显示。
- 新增轻微左／右弯、连续小弯及先左／先右、靠外、岔路左／右转和颠簸路图案。轻微弯不使用虚构的数字等级。
- 包含此前本地版本的切弯、小切弯、低洼路、刹车、岔路、靠左／右／内，以及左／右长弯、短弯和编号变急组合。“左4变急到2”会保留起始和目标数字。
- 连续播报会短暂补显尚未显示的子提示，已显示的旧弯道不重复轮播。补显最多两条，额外等待上限为 700 毫秒；超限时优先避免持续积压旧提示。
- 路书使用与交通灯一致的红、黄、绿配色，数字保持白色。
- 包含通用及欧卡／美卡车辆灯光遥测、自定义布尔遥测代码入口，以及 ACR 灯光状态、转向灯实际亮灭和语音路书同步支持。

## 使用与兼容性

完成插件更新后重新打开 SimHub。ACR 路书在“矩阵灯盘”中启用“路书跟随语音播报”；需要输出到实体灯盘的手动预览应勾选“同步输出至灯盘”，测试完成后恢复实时灯态。

ACR 原生采集依赖受支持的游戏版本及游戏适配。未安装适配的电脑需使用插件中的 ACR 安装／修复入口；本次发布保留已验证的 `0.4.0` 适配，不加入曾导致崩溃的诊断钩子。游戏更新后遇到不支持的版本，采集会停止，不猜测状态。

未知播报不会伪装成某个已支持弯道。当前两段问题现场采集及历史播报回放均已通过，但不代表所有赛段、车辆、语音和提示组合均完成实体测试。

客户原有配置保留，升级前备份，失败回滚。在线包符合旧更新器的 32 MiB 下载上限，仍内置 AVR 更新工具；此次插件更新不刷写固件，X1 和 APEX2 固件版本及文件均不变。
